# 🦌 Охотминимум: закономерности вместо зубрёжки

Шпаргалка для подготовки к экзамену на охотничий билет (охотминимум) — разбор всех **257 вопросов** из официального перечня Минприроды России.

**➡️ Открыть шпаргалку: https://ivanrazmakhov.github.io/ohotminimum/**

## Зачем это

Официальный перечень — 48 страниц сплошных вопросов без структуры. Учить их подряд тяжело и бессмысленно: внутри полно повторов, пар-двойников и закономерностей, которые сокращают реальный объём зубрёжки в разы.

Этот сайт — не пересказ билетов, а **выжимка паттернов**:

- 📅 **Датовые блоки** — вместо ~100 отдельных сроков охоты учишь ~15 групп («осенняя четвёрка» копытных, «горная пятёрка», линия стартов пушных)
- ⚠️ **Вопросы-ловушки** — перевёртыши, числовые приманки и пары «похожий вопрос — противоположный ответ»
- 🎯 **Алгоритм угадывания** — что ставить, если ответ вылетел из головы (спойлер: статистика по буквам вариантов сильно неравномерная)

## Структура

Темы соответствуют разбивке популярных сайтов-тренажёров:

| Раздел | Что внутри |
|---|---|
| 1. Общие темы | определения, биология, перевёртыш «спячка/зимний сон» |
| 2. Правила охоты | 6 сквозных паттернов: документы, транспортировка, запреты, коллективная охота |
| 3. Копытные | датовые блоки, три схемы для взрослых самцов |
| 4. Медведи | два сезона бурого, «окно тишины», квоты и отчёты |
| 5. Пушные | линия стартов от весны к осени, пары-двойники |
| 6. Пернатая дичь | классификация 5 групп, правило суббот, весенние ограничения |
| Все даты | сводная таблица: 8 дат окончаний, 5 минимумов сезона |
| Советы | маркер-фразы правильных ответов и алгоритм на экзамене |

## Как пользоваться

1. Пройди темы по порядку — сначала паттерны, потом ловушки.
2. Выучи сводную таблицу дат (это ~20 строк вместо сотни вопросов).
3. Прогони себя на любом сайте-тренажёре, возвращаясь сюда за разбором ошибок.
